# LabLLM Discussions

Use Discussions for community conversation, early ideas, help, workflows, and sharing what you trained.

Use Issues for reproducible bugs and scoped implementation work.

## Categories

- **Announcements**: release notes, roadmap updates, compatibility notes, and maintainer news.
- **General**: open-ended product, workflow, and community discussion.
- **Ideas**: feature concepts before they become scoped issues.
- **Q&A**: how-to questions that can have a marked answer.
- **Show and tell**: models, datasets, recipes, screenshots, training runs, and demos.
- **Polls**: lightweight voting when a maintainer wants community direction.

## Good Discussion Posts

Useful posts usually include:

- What you are trying to do.
- What dataset/model/settings are involved.
- What happened.
- What answer, decision, or feedback would help.

## Where To Post

- Need help using LabLLM? Start a **Q&A** discussion.
- Have a feature idea? Start an **Ideas** discussion.
- Found a reproducible crash? Open a bug issue instead.
- Trained something interesting? Use **Show and tell**.
- Want to propose a big direction change? Start in **General** before opening a PR.
