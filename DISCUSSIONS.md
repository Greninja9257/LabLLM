# LabLLM Community

Use Discussions for community conversation, early ideas, help, workflows, and sharing what you trained.

Use Issues for reproducible bugs and scoped implementation work.

## Categories

- **Release Notes**: beta builds, roadmap changes, compatibility notes, and maintainer updates.
- **Lab Talk**: open-ended product, workflow, education, and community discussion.
- **Feature Lab**: rough ideas before they become scoped issues.
- **Help Desk**: how-to questions that can have a marked answer.
- **Model Gallery**: models, datasets, recipes, screenshots, training runs, and demos.
- **Community Votes**: lightweight polls when a maintainer wants direction.

## Good Discussion Posts

Useful posts usually include:

- What you are trying to do.
- What dataset/model/settings are involved.
- What happened.
- What answer, decision, or feedback would help.

## Where To Post

- Need help using LabLLM? Start a **Help Desk** discussion.
- Have a feature idea? Start a **Feature Lab** discussion.
- Found a reproducible crash? Open a bug issue instead.
- Trained something interesting? Use **Model Gallery**.
- Want to propose a big direction change? Start in **Lab Talk** before opening a PR.

## Maintainer Setup

GitHub stores Discussion category names in repository settings, not in git. Keep the default category slugs so the templates keep working, but rename the visible categories in GitHub:

- Announcements -> Release Notes
- General -> Lab Talk
- Ideas -> Feature Lab
- Q&A -> Help Desk
- Show and tell -> Model Gallery
- Polls -> Community Votes
