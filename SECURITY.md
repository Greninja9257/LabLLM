# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security-sensitive reports.

Instead, contact the project owner through GitHub and include:

- A short description of the issue.
- Steps to reproduce.
- Impact and affected versions, if known.
- Any suggested mitigation.

## Scope

Security-sensitive areas include:

- Unsafe model or dataset loading.
- Malicious file import behavior.
- Local server authentication or exposure.
- Data deletion or privacy bugs.
- Dependency vulnerabilities.

LabLLM is a beta project, so reports with clear reproduction steps are especially valuable.
